# GunBeep

โปรแกรมคุมมาโครลดแรงดีด (recoil) ของ PUBG ที่ทำงานคู่กับสคริปต์ Lua ใน Logitech G Hub
มีหน้าต่างเปิด/ปิด เลือกชุดค่าปืน เสียงแจ้งเตือน และตั้งค่า G Hub ให้อัตโนมัติ

> ⚠️ มาโครลดแรงดีดผิดกฎของเกมออนไลน์ส่วนใหญ่ ถ้าระบบ anti-cheat ตรวจเจออาจโดนแบนบัญชีได้

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | คืออะไร |
|---|---|
| `GunBeep.exe` | ตัวโปรแกรม ดับเบิลคลิกใช้ได้เลย ไม่ต้องลงอะไรเพิ่ม (.NET อยู่ในไฟล์ .dll ข้างๆ — อย่าแยก .exe ออกจากโฟลเดอร์) |
| `logitech-g-hub-2021-11-8744.exe` | ตัวติดตั้ง G Hub เวอร์ชัน 2021.11 (GunBeep หาไฟล์นี้เองตอนติดตั้ง) |
| `recoil.lua` | สคริปต์ G Hub (ฝังอยู่ใน GunBeep.exe แล้ว ไฟล์นี้ไว้ดู/แก้) |
| `saved\` | GunBeep เก็บค่าไว้ตรงนี้อัตโนมัติ: `settings.json` (ปุ่มลัด ชื่อปืน ฯลฯ) และ `guns.lua` (ตารางปืนที่จูนแล้ว) |
| `GunBeepApp\` | ซอร์สโค้ด |
| `build.ps1` | สร้าง GunBeep.exe ใหม่จากซอร์ส (ต้องมี .NET 10 SDK) |
| `CLAUDE.md` | บันทึกรายละเอียดเทคนิคไว้ให้ Claude อ่านตอนมาถามต่อ |

**เก็บทั้งโฟลเดอร์นี้ไว้** (เช่นใน USB / Google Drive) แล้วก๊อปกลับมาวางหลังลง Windows ใหม่

## อัปเดตอัตโนมัติ (GitHub)
- โค้ดอยู่ที่ https://github.com/BenjaminKiass/GunBeep
- ทุกครั้งที่ push ขึ้น `main` GitHub จะ build แล้วออก Release ใหม่ให้เอง (`v1.0.<ลำดับ>`)
- GunBeep เช็กตอนเปิดและทุก 6 ชั่วโมง → ถ้ามีเวอร์ชันใหม่ จะขึ้นปุ่ม **⬆ อัปเดต** มุมขวาบน กดแล้วโหลดมาทับและเปิดใหม่เอง (`saved\` ไม่หาย)
- ถ้าสคริปต์ใน G Hub เปลี่ยนเวอร์ชันด้วย กล่อง G Hub จะขึ้นสีส้ม → กด **ตั้งค่าอัตโนมัติ**
- ดาวน์โหลดครั้งแรก: หน้า Releases → `GunBeep-win-x64.zip` → แตกไฟล์ → เปิด `GunBeep.exe`
- ตัวติดตั้ง G Hub ไม่ได้อยู่ใน GitHub (ไฟล์ลิขสิทธิ์ของ Logitech) — เก็บไว้เองแล้ววางข้าง `GunBeep.exe` หรือใน `Downloads\มาโครพับจี`

## ลง Windows ใหม่: ทำตามนี้

1. ลง Steam + PUBG ให้เรียบร้อย
2. ก๊อปโฟลเดอร์นี้ลงเครื่อง แล้วเปิด `GunBeep.exe`
   - ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway** (เพราะโปรแกรมไม่ได้ซื้อใบรับรอง)
3. ในกล่อง **Logitech G Hub** ด้านล่าง กด **ตั้งค่าอัตโนมัติ** → ถ้ายังไม่มี G Hub จะเปิดตัวติดตั้งให้ (กด Yes ที่ UAC)
4. เปิด G Hub แล้วให้มันเจอ PUBG (เปิดเกมหนึ่งครั้ง หรือกด Add game ใน G Hub)
5. ใน G Hub: เลือก PUBG → โปรไฟล์ Default → ไอคอน **Scripting** → **Create new Lua script** → ปิดหน้าสคริปต์
   (G Hub ไม่ยอมให้โปรแกรมอื่นสร้างสคริปต์ให้ ต้องทำเองครั้งเดียว)
6. กลับมาที่ GunBeep กด **ตั้งค่าอัตโนมัติ** อีกครั้ง → จะใส่สคริปต์ (พร้อมค่าที่จูนไว้จาก `saved\guns.lua`) + ล็อกโปรไฟล์ PUBG + รีสตาร์ท G Hub
7. ทั้ง 3 ข้อในกล่อง G Hub ขึ้นจุดเขียว = พร้อมใช้

ถ้าอยากคง G Hub เวอร์ชัน 2021.11 ไว้ ให้ปิดการอัปเดตอัตโนมัติใน G Hub (Settings → ปิด automatic updates)

## วิธีใช้

| ทำอะไร | ปุ่ม |
|---|---|
| เปิด/ปิดมาโคร | **F8** (เปลี่ยนได้ในโปรแกรม) หรือคลิกปุ่มวงกลม |
| วนชุดค่าปืน 1 → 2 → 3 | ปุ่ม **Back** ข้างเมาส์ (ได้เฉพาะตอนเปิดมาโคร) |
| จูนแรงดึงลง +0.5 / −0.5 | **Ctrl + Back** / **Alt + Back** |
| จูนซ้าย-ขวา +0.5 / −0.5 | **Shift+Ctrl + Back** / **Shift+Alt + Back** |
| ดึงซ้าย/ขวาเพิ่มชั่วคราวตอนยิง | กด **Alt** / **Ctrl** ค้าง |
| ตั้งชื่อปืน | ดับเบิลคลิกการ์ดปืนในโปรแกรม (ชื่อภาษาอังกฤษจะถูกพูดออกเสียง) |

ตอนมาโครปิด ปุ่มข้างเมาส์จะไม่ทำอะไรเลย กันค่าเพี้ยน

**ป้ายบนจอเกม:** ป้ายเล็กๆ ที่มุมจอบอก ON/OFF + ปืนที่ใช้ + base/x และเด้งบอกตอนจูนค่า/ส่งค่าเข้า G Hub
- ปุ่ม "ป้ายบนจอเกม" กดวน: **ปิด** → **ตอนเปลี่ยน** (โผล่ 2.5 วินาทีตอนเปิด/ปิด/เปลี่ยนปืน/จูน) → **ตลอด**
- ปุ่ม "ตำแหน่งป้าย" กดวน 4 มุมจอ
- ป้ายคลิกทะลุได้ ไม่แย่งเมาส์/คีย์บอร์ดจากเกม
- ขึ้นได้เฉพาะเกมโหมด **Borderless / Windowed** (ถ้า PUBG ตั้งเป็น Fullscreen ป้ายจะไม่ขึ้น)

**โลโก้:** วางรูปชื่อ `logo.png` (สี่เหลี่ยมจัตุรัส) ไว้ข้าง `GunBeep.exe` แล้วเปิดโปรแกรมใหม่ — ใช้เป็นโลโก้หัวโปรแกรมและไอคอนที่ถาด

**เปิดพร้อม Windows:** เปิดสวิตช์ในโปรแกรม → เข้า Windows แล้ว GunBeep จะเปิดเองแบบย่ออยู่ที่ถาด (มาโครปิดไว้ก่อนเสมอ)
ดับเบิลคลิกไอคอนที่ถาด หรือดับเบิลคลิก `GunBeep.exe` อีกครั้ง = เด้งหน้าต่างขึ้นมา ถ้าย้ายโฟลเดอร์ GunBeep ให้เปิดจากที่ใหม่หนึ่งครั้ง โปรแกรมจะแก้ที่อยู่ให้เอง

### หลอดเลื่อนปรับค่า (real time)
- คลิกการ์ดปืน → เลื่อนหลอด "แรงดึงลง" / "ซ้าย/ขวา" หรือกด − / + (ทีละ 0.5)
- ปล่อยหลอดครึ่งวินาที GunBeep ส่งค่าเข้า G Hub ให้ทันที ไม่ต้องรีสตาร์ท (ระหว่างส่ง ~1 วินาที ไฟ Caps Lock จะกะพริบแล้วกลับเหมือนเดิม)
- ถ้า G Hub ไม่ตอบรับ (สคริปต์เก่า) ปุ่มจะเปลี่ยนเป็น "ใช้ค่านี้ (รีสตาร์ท G Hub)" แทน

### ค่าที่จูน (เซฟให้อัตโนมัติ)
- การ์ดปืนแต่ละใบโชว์ค่า `base` / `x` ปัจจุบัน — จูนด้วย Ctrl/Alt + Back แล้วตัวเลขเปลี่ยนทันที
- GunBeep เซฟค่าลงไฟล์สคริปต์ของ G Hub และ `saved\guns.lua` ให้เอง ไม่ต้องก๊อปจาก Console แล้ว
- ข้อควรระวัง: ถ้าเปิดหน้า Scripting ของ G Hub ค้างไว้แล้วกด Save ในนั้น G Hub จะเขียนโค้ดในหน้าจอทับค่าที่ GunBeep เซฟไว้
  (ปิดหน้า Scripting ก่อนจูน หรือกด "ตั้งค่าอัตโนมัติ" ใหม่หลังแก้ในนั้น)

### ข้อควรรู้
- GunBeep ส่งสถานะให้ G Hub ผ่านไฟ **Scroll Lock + Num Lock** — ระหว่างเล่นอย่ากดสองปุ่มนี้เอง
- ปิด GunBeep = มาโครหยุดทันที
- ไฟล์ของ G Hub ที่ GunBeep เคยแก้ ถูกสำรองไว้ที่ `%APPDATA%\GunBeep\backups`

## Malwarebytes / แอนตี้ไวรัส
โปรแกรมดักปุ่มคีย์บอร์ดและแก้ไฟล์ของ G Hub ทำให้แอนตี้ไวรัสอาจเข้าใจผิด ให้เพิ่มโฟลเดอร์นี้ไว้ในรายการยกเว้น:
- Malwarebytes → Settings → **Allow List** → **Add** → **Allow a file or folder** → เลือกโฟลเดอร์ `GunBeep`
  (ติ๊กให้ยกเว้นทุกการตรวจจับ ถ้ามีตัวเลือก)

## แก้ปัญหา

| อาการ | ลองทำ |
|---|---|
| กด F8 แล้ว Console ไม่ขึ้น `MACRO ON` | เช็กว่ากล่อง G Hub ใน GunBeep เขียวครบ / กด ตั้งค่าอัตโนมัติ อีกครั้ง |
| ยิงแล้วไม่ดึง | เช็กว่าเข้าเกมแล้ว G Hub ยังอยู่ที่โปรไฟล์ PUBG (มีรูปกุญแจ) |
| ปุ่ม Back ไม่ทำงาน | ต้องเปิดมาโครก่อน / ถ้ายังไม่ได้ ลองเปลี่ยน `CYCLE_BTN` ใน recoil.lua |
| ไม่มีเสียง | เช็กสวิตช์ "เสียงแจ้งเตือน" ในโปรแกรม และลำโพงหลักของ Windows |
