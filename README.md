# GunBeep

โปรแกรมคุมมาโครลดแรงดีด (recoil) ของ PUBG ที่ทำงานคู่กับสคริปต์ Lua ใน Logitech G Hub
มีหน้าต่างเปิด/ปิด เลือกชุดค่าปืน เสียงแจ้งเตือน และตั้งค่า G Hub ให้อัตโนมัติ

> ⚠️ มาโครลดแรงดีดผิดกฎของเกมออนไลน์ส่วนใหญ่ ถ้าระบบ anti-cheat ตรวจเจออาจโดนแบนบัญชีได้

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | คืออะไร |
|---|---|
| `GunBeep.exe` | ตัวโปรแกรม ดับเบิลคลิกใช้ได้เลย ไม่ต้องลงอะไรเพิ่ม (.NET อยู่ในไฟล์ .dll ข้างๆ — อย่าแยก .exe ออกจากโฟลเดอร์) |
| `logitech-g-hub-2021-11-8744.exe` | ตัวติดตั้ง G Hub เวอร์ชัน 2021.11 (GunBeep หาไฟล์นี้เองตอนติดตั้ง) |
| `recoil.lua` | สคริปต์ G Hub (ฝังอยู่ใน GunBeep.exe แล้ว ไฟล์นี้ไว้ดู/แก้) |
| `saved\` | GunBeep เก็บค่าไว้ตรงนี้อัตโนมัติ: `settings.json` (ปุ่มลัด ชื่อปืน ฯลฯ) และ `guns.lua` (ตารางปืนที่จูนแล้ว) |
| `GunBeepApp\` | ซอร์สโค้ด |
| `build.ps1` | สร้าง GunBeep.exe ใหม่จากซอร์ส (ต้องมี .NET 10 SDK) |
| `CLAUDE.md` | บันทึกรายละเอียดเทคนิคไว้ให้ Claude อ่านตอนมาถามต่อ |

**เก็บทั้งโฟลเดอร์นี้ไว้** (เช่นใน USB / Google Drive) แล้วก๊อปกลับมาวางหลังลง Windows ใหม่

- ถ้าสคริปต์ใน G Hub เปลี่ยนเวอร์ชันด้วย กล่อง G Hub จะขึ้นสีส้ม → กด **ตั้งค่าอัตโนมัติ**
- ดาวน์โหลดครั้งแรก: หน้า Releases → `GunBeep-win-x64.zip` → แตกไฟล์ → เปิด `GunBeep.exe`
- ตัวติดตั้ง G Hub ไม่ได้อยู่ใน GitHub (ไฟล์ลิขสิทธิ์ของ Logitech) — เก็บไว้เองแล้ววางข้าง `GunBeep.exe` หรือใน `Downloads\มาโครพับจี`

## ลง Windows ใหม่: ทำตามนี้

1. ลง Steam + PUBG ให้เรียบร้อย
2. ก๊อปโฟลเดอร์นี้ลงเครื่อง แล้วเปิด `GunBeep.exe`
   - ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway** (เพราะโปรแกรมไม่ได้ซื้อใบรับรอง)
3. ในกล่อง **Logitech G Hub** ด้านล่าง กด **ตั้งค่าอัตโนมัติ** → ถ้ายังไม่มี G Hub จะเปิดตัวติดตั้งให้ (กด Yes ที่ UAC)
4. เปิด G Hub แล้วให้มันเจอ PUBG (เปิดเกมหนึ่งครั้ง หรือกด Add game ใน G Hub)
5. ใน G Hub: เลือก PUBG → โปรไฟล์ Default → ไอคอน **Scripting** → **Create new Lua script** → ปิดหน้าสคริปต์
   (G Hub ไม่ยอมให้โปรแกรมอื่นสร้างสคริปต์ให้ ต้องทำเองครั้งเดียว)
6. กลับมาที่ GunBeep กด **ตั้งค่าอัตโนมัติ** อีกครั้ง → จะใส่สคริปต์ (พร้อมค่าที่จูนไว้จาก `saved\guns.lua`) + ล็อกโปรไฟล์ PUBG + รีสตาร์ท G Hub
7. ทั้ง 3 ข้อในกล่อง G Hub ขึ้นจุดเขียว = พร้อมใช้

ถ้าอยากคง G Hub เวอร์ชัน 2021.11 ไว้ ให้ปิดการอัปเดตอัตโนมัติใน G Hub (Settings → ปิด automatic updates)

## วิธีใช้

| ทำอะไร | ปุ่ม |
|---|---|
| เปิด/ปิดมาโคร | **F8** (เปลี่ยนได้ในโปรแกรม) หรือคลิกปุ่มวงกลม |
| วนชุดค่าปืน 1 → 2 → 3 | ปุ่ม **Back** ข้างเมาส์ (ได้เฉพาะตอนเปิดมาโคร) |
| จูนแรงดึงลง +0.5 / −0.5 | **Ctrl + Back** / **Alt + Back** |
| จูนซ้าย-ขวา +0.5 / −0.5 | **Shift+Ctrl + Back** / **Shift+Alt + Back** |
| ดึงซ้าย/ขวาเพิ่มชั่วคราวตอนยิง | กด **Alt** / **Ctrl** ค้าง |
| ตั้งชื่อปืน | ดับเบิลคลิกการ์ดปืนในโปรแกรม |

ตอนมาโครปิด ปุ่มข้างเมาส์จะไม่ทำอะไรเลย กันค่าเพี้ยน

**ป้ายบนจอเกม:** ป้ายเล็กๆ ที่มุมจอบอก ON/OFF + ปืนที่ใช้ + base/x และเด้งบอกตอนจูนค่า/ส่งค่าเข้า G Hub
- ปุ่ม "ป้ายบนจอเกม" กดวน: **ปิด** → **ตอนเปลี่ยน** (โผล่ 2.5 วินาทีตอนเปิด/ปิด/เปลี่ยนปืน/จูน) → **ตลอด**
- ปุ่ม "ตำแหน่งป้าย" กดวน 4 มุมจอ
- ป้ายคลิกทะลุได้ ไม่แย่งเมาส์/คีย์บอร์ดจากเกม
- ขึ้นได้เฉพาะเกมโหมด **Borderless / Windowed** (ถ้า PUBG ตั้งเป็น Fullscreen ป้ายจะไม่ขึ้น)

**โลโก้:** วางรูปชื่อ `logo.png` (สี่เหลี่ยมจัตุรัส) ไว้ข้าง `GunBeep.exe` แล้วเปิดโปรแกรมใหม่ — ใช้เป็นโลโก้หัวโปรแกรมและไอคอนที่ถาด

**เปิดพร้อม Windows:** เปิดสวิตช์ในโปรแกรม → เข้า Windows แล้ว GunBeep จะเปิดเองแบบย่ออยู่ที่ถาด (มาโครปิดไว้ก่อนเสมอ)
ดับเบิลคลิกไอคอนที่ถาด หรือดับเบิลคลิก `GunBeep.exe` อีกครั้ง = เด้งหน้าต่างขึ้นมา ถ้าย้ายโฟลเดอร์ GunBeep ให้เปิดจากที่ใหม่หนึ่งครั้ง โปรแกรมจะแก้ที่อยู่ให้เอง

### จอยืดตอนเปิดเกม (เล่น Borderless แบบยืด)
- ปุ่ม **"จอยืดตอนเปิดเกม"** → เลือกความละเอียด (เช่น 1728×1080) → เปิด PUBG เมื่อไหร่ GunBeep เปลี่ยนความละเอียด Windows ให้ ปิดเกมแล้วคืนค่าเดิม
- ตั้ง PUBG เป็น **Borderless** (ป้ายบนจอถึงจะขึ้น) + NVIDIA Control Panel → Adjust desktop size → Scaling = **Full-screen**, Perform scaling on **GPU**, ติ๊ก Override
- ถ้าไม่มีความละเอียดที่ต้องการในรายการ: NVIDIA Control Panel → Change resolution → Customize → Create Custom Resolution
- เปลี่ยนแบบชั่วคราว (ไม่เขียนลง Windows) — ถ้าเครื่องค้าง/รีสตาร์ท จะกลับเป็นความละเอียดเดิมเอง
- เปิด GunBeep ทีหลังเกม หรืออัปเดตกลางเกม: GunBeep ยืดจอแล้วขยายหน้าต่างเกมให้พอดีเอง
- ถ้าภาพเกมล้น/โดนตัดขอบ: ในเกมเปลี่ยนโหมดการแสดงผลเป็น Windowed แล้วกลับเป็น Borderless
- ในเมนูเดียวกันเลือก **ยืดตลอด** ได้: ยืดตั้งแต่เปิด GunBeep จนปิด GunBeep ไม่ต้องรอเกม
- ถ้าจอเด้งกลับเอง (ตื่นจาก sleep ฯลฯ) GunBeep ยืดกลับให้

### อัดค่าแรงดึงอัตโนมัติ
- ปุ่ม **อัดค่า** (ข้างปุ่มกราฟ) → เลือกปืน 1/2/3 → หน้าต่างเปิดทิ้งไว้แล้วเข้าเกมได้เลย
- **ปิดมาโคร** → ยิงค้างใส่กำแพงในห้องซ้อม แล้ว**ลากเมาส์ลงเอง**ให้เป้าอยู่จุดเดิมให้มากที่สุด ทำ 3–5 ชุด (ป้ายบนจอบอกทุกชุด + ค่าที่คำนวณได้)
- กลับมากด **ใช้ค่านี้** → ตั้ง base / x / กราฟ ให้ปืนนั้น และส่งเข้า G Hub ทันที (เซฟลงไฟล์ด้วย)
- GunBeep อัดการเคลื่อนเมาส์จริงทุก 10 ms (Raw Input หน่วยเดียวกับที่มาโครขยับ) เฉลี่ยทุกชุด ตัดชุดที่ต่างจากชุดอื่นเกิน 40% ทิ้ง
  — base = แรงดึงช่วงที่ต่ำสุด, กราฟ = ส่วนที่เพิ่มตามเวลา, x = ซ้าย/ขวาเฉลี่ย
- ผลออกมาเท่ากับ "มือคุณ" ตอนกดดีที่สุด — ถ้ายังดึงเกิน/ไม่พอ ปรับ base ด้วย Ctrl/Alt + Back ต่อได้
- **ปุ่มในเกม:** ปุ่ม "ในเกม: ..." เหนือการ์ดปืน → เลือกเมาส์ Back / Forward / ปุ่มกลาง หรือปุ่มคีย์บอร์ดอะไรก็ได้ (กดเปล่า = วนปืน, Ctrl/Alt = base ±0.5, Shift+Ctrl/Alt = ซ้าย/ขวา) — ปุ่มเมาส์ต้องใช้สคริปต์ v7 (กด ตั้งค่าอัตโนมัติ ครั้งเดียว)
- **จูนละเอียด:** เปิดมาโคร (ปืนเดียวกับแท็บ) → ยิงแล้วดึงแก้เฉพาะส่วนที่มาโครยังขาด/เกิน 3 ชุด → ใช้ค่านี้ → ทำซ้ำจนขึ้น **"นิ่งแล้ว ✓"**
  ค่าจะเข้ากับมือ เมาส์ และ sens ของแต่ละคน
- **สลับปืนตามช่อง:** ตั้งค่า "สลับปืนตามช่อง" → ในเกมกด 1 = ปืน 1, 2 = ปืน 2, ลูกกลิ้ง = สลับช่อง (เฉพาะตอนเปิดมาโคร)
- **ปุ่มลัดเป็นปุ่มเมาส์ได้:** กดปุ่มตั้งปุ่มลัด แล้วคลิกเมาส์ปุ่มกลาง / Back / Forward
- **👁 จูนด้วยตา (แนะนำ ง่ายสุด):** กดปุ่ม "จูนด้วยตา" ในโปรแกรม → เข้าเกม ป้ายมุมจอบอกทุกขั้น: มือนิ่ง ยิงค้างจนป้ายบอกให้ปล่อย → ดูรอยกระสุน → ตอบด้วยลูกศร (⬆ ลอยขึ้น ⬇ ตกลง ➡ พอดี; ซ้าย/ขวา: ⬅ ➡ และ ⬆ = ตรงแล้ว) → ทำจนป้ายขึ้นว่าจูนเสร็จ (Esc = ยกเลิก)
- **จูนจากรอยกระสุน:** เปิดมาโคร มือนิ่ง ยิงหมดแม็กใส่กำแพง ดูรอย → ลากบนกราฟเลือกช่วงเวลาที่หลุด (นับจากเริ่มกดยิง) แล้วกด "หลุดขึ้น/หลุดลง" หรือ "หลุดซ้าย/ขวา" ทีละ 0.5 → ยิงดูใหม่จนเป็นกระจุกเดียว (ไม่ต้องดึงแก้เอง)
- **ออโต้จูน:** กด **▶ ออโต้จูน** → เปิดมาโคร ยิงค้างไปเรื่อยๆ แล้วดึงแก้เฉพาะส่วนที่เป้ายังขยับ → ทุก 3 ชุดปรับค่าและส่งเข้า G Hub เอง
  → นิ่งติดกัน 2 รอบ = เสร็จ หยุดเอง (ตามปืนที่มาโครใช้อยู่ให้เอง) — ระบบรู้ว่าต้องปรับแค่ไหนจากที่มือคุณแก้ ถ้าไม่แก้เลยจะถือว่านิ่งแล้ว
- ไม่อ่านภาพจากเกมเลย (ไม่เข้าข่ายโปรแกรมอ่านจอ)

### ระหว่างยิง
- **โหมดยิง** (ปุ่ม "โหมด"): ดึงทุกครั้งที่ยิง / ดึงเฉพาะตอนเล็งคลิกขวา (กดค้าง หรือกดสั้นๆ ทีเดียวให้สโคปค้าง กดอีกทีออก)
- **หยุดเองตอนเปิดกระเป๋า / แผนที่ / เมนู** หรือสลับออกจากเกม — ดูแค่ว่าเคอร์เซอร์ Windows โผล่หรือไม่ (ไม่อ่านภาพเกม) เปิดมาโครทิ้งไว้ทั้งเกมได้
- **หยุดดึงหลังยิง N นัด** (ค่าเริ่มต้น 42 = แม็ก 40 + เผื่อ 2, ปรับ 5–120 ด้วยหลอด / − + / พิมพ์ตัวเลข) กระสุนหมดแล้วกดค้าง จอไม่กดลงต่อ
  นับจากเวลา 1 นัด ≈ 0.086 วิ (ไรเฟิลส่วนใหญ่) แม็ก 30 นัดตั้ง 32

### SOCD (ปุ่มทิศชนกัน แบบคีย์บอร์ด Snap Tap)
- แถว **"SOCD"** ในกล่องตั้งค่า → เปิด/ปิด, เลือกโหมด: **ปุ่มล่าสุดชนะ** (กด A ค้างแล้วแตะ D = ไปขวาทันที ปล่อย D = กลับซ้าย) / ปุ่มแรกชนะ / กดคู่ = หยุดนิ่ง
- เพิ่ม/ลบคู่ปุ่มได้ (ค่าเริ่มต้น A ⇄ D) กด "เพิ่มคู่ปุ่ม" แล้วกดปุ่มบนคีย์บอร์ดทีละตัว
- ติ๊ก "ใช้เฉพาะตอนอยู่ในเกม PUBG" ไว้ = พิมพ์งานนอกเกมไม่โดน — ใช้ได้กับคีย์บอร์ดทุกยี่ห้อ (Rapid Trigger ต้องใช้คีย์บอร์ดสวิตช์แม่เหล็ก ทำด้วยโปรแกรมไม่ได้)
- บางเกม (เช่น CS2) ห้ามระบบแบบนี้ — PUBG ยังไม่เห็นประกาศห้าม แต่ไม่รับประกัน

### หลอดเลื่อนปรับค่า (real time)
- คลิกการ์ดปืน → เลื่อนหลอด "แรงดึงลง" / "ซ้าย/ขวา" หรือกด − / + (ทีละ 0.5)
- ปล่อยหลอดครึ่งวินาที GunBeep ส่งค่าเข้า G Hub ให้ทันที ไม่ต้องรีสตาร์ท (ระหว่างส่ง ~1 วินาที ไฟ Caps Lock จะกะพริบแล้วกลับเหมือนเดิม)
- ถ้า G Hub ไม่ตอบรับ (สคริปต์เก่า) ปุ่มจะเปลี่ยนเป็น "ใช้ค่านี้ (รีสตาร์ท G Hub)" แทน

### กราฟแรงดีด (segs)
- ปุ่ม **กราฟแรงดีด** ใต้หลอดเลื่อน → หน้าต่างกราฟ แท่งละ 0.1 วินาที (สูง = ดึงลงแรงขึ้นช่วงนั้น)
- **ลากเมาส์ระบาย**บนกราฟเพื่อปรับ, แท็บ 1/2/3 = เลือกปืน, ปุ่ม: ทั้งเส้น ±0.5 · เกลี่ยให้เรียบ · คัดลอกจากปืนอื่น · ค่าเริ่มต้น · ย้อนกลับ (Ctrl+Z)
- แรงดึงจริง = base + ค่าในกราฟ (ทุก 10 ms) — เอาเมาส์ชี้แท่งจะบอกตัวเลขให้
- กด **บันทึก + ใช้เลย** → ส่งกราฟเข้า G Hub แบบ real time ไม่ต้องรีสตาร์ท (~2–10 วิ ตามความซับซ้อนของกราฟ, ป้ายบนจอบอกระหว่างส่ง)
  - ต้องใช้สคริปต์ G Hub **v6** (กล่อง G Hub ขึ้นสีส้ม → กด ตั้งค่าอัตโนมัติ หนึ่งครั้ง) — สคริปต์รุ่นเก่าจะใช้วิธีรีสตาร์ท G Hub แทน
  - กราฟที่แก้จะถูกปัดเป็นแท่งละ 0.1 วิ ค่าละเอียด 0.25 (สูงสุด 31.75) ให้ตรงกับที่ส่งจริง
  - ไฟล์สคริปต์เดิมถูกสำรองไว้ใน `%APPDATA%\GunBeep\backups` ทุกครั้งที่เขียน
- โปรไฟล์เก็บกราฟไปด้วย — เลือกโปรไฟล์หรือกด F9 แล้วกราฟเปลี่ยนตามทันที (สคริปต์ v6)

### โปรไฟล์ค่าปืน (เก็บหลายชุด / ส่งออก / นำเข้า)
- **บันทึก** = เก็บชื่อปืน + base/x ทั้ง 3 ชุดตอนนี้เป็นโปรไฟล์ (ตั้งชื่อเอง เช่น "เมาส์ใหม่", "sens 40")
- ปุ่ม **▾ ชื่อโปรไฟล์** = เลือกโปรไฟล์ → ค่าส่งเข้า G Hub ทันทีไม่ต้องรีสตาร์ท (มี • ต่อท้าย = ค่าถูกแก้ไปจากโปรไฟล์แล้ว)
- **ปุ่มสลับโปรไฟล์ (ค่าเริ่มต้น F9)** = กดในเกมเพื่อวนโปรไฟล์ถัดไปทันที — ป้ายบนจอบอกชื่อ (เช่น 2/3)
  - ไม่มีหน้าต่างถามกลางเกม: ถ้าค่าตอนนั้นยังไม่ได้บันทึก จะเก็บไว้ให้เป็นโปรไฟล์ "ก่อนสลับ (อัตโนมัติ)" ก่อน
  - ใช้ base/x และกราฟทันที (สคริปต์ v6) — ถ้ายังเป็นสคริปต์รุ่นเก่า กราฟจะยังไม่เปลี่ยนและป้ายจะบอก
  - เปลี่ยนปุ่มได้ที่ "ปุ่มสลับโปรไฟล์" ในโปรแกรม (กด Delete ตอนตั้ง = ไม่ใช้)
- **นำเข้า / ส่งออก** = ส่งออกเป็นไฟล์ `.json` ให้เพื่อน / นำเข้าไฟล์จากเพื่อน, ลบโปรไฟล์, เปิดโฟลเดอร์
- โปรไฟล์เก็บใน `saved\presets\` (อยู่ในโฟลเดอร์ saved — ลง Windows ใหม่ / อัปเดตแล้วไม่หาย)

### ค่าที่จูน (เซฟให้อัตโนมัติ)
- การ์ดปืนแต่ละใบโชว์ค่า `base` / `x` ปัจจุบัน — จูนด้วย Ctrl/Alt + Back แล้วตัวเลขเปลี่ยนทันที
- GunBeep เซฟค่าลงไฟล์สคริปต์ของ G Hub และ `saved\guns.lua` ให้เอง ไม่ต้องก๊อปจาก Console แล้ว
- ข้อควรระวัง: ถ้าเปิดหน้า Scripting ของ G Hub ค้างไว้แล้วกด Save ในนั้น G Hub จะเขียนโค้ดในหน้าจอทับค่าที่ GunBeep เซฟไว้
  (ปิดหน้า Scripting ก่อนจูน หรือกด "ตั้งค่าอัตโนมัติ" ใหม่หลังแก้ในนั้น)

### ข้อควรรู้
- GunBeep ส่งสถานะให้ G Hub ผ่านไฟ **Scroll Lock** (สคริปต์ v16+ ไม่ใช้ Num Lock แล้ว เพราะใน PUBG Num Lock = วิ่งอัตโนมัติ) — ระหว่างเล่นอย่ากด Scroll Lock เอง
- ปิด GunBeep = มาโครหยุดทันที
- ไฟล์ของ G Hub ที่ GunBeep เคยแก้ ถูกสำรองไว้ที่ `%APPDATA%\GunBeep\backups`

## Malwarebytes / แอนตี้ไวรัส
โปรแกรมดักปุ่มคีย์บอร์ดและแก้ไฟล์ของ G Hub ทำให้แอนตี้ไวรัสอาจเข้าใจผิด ให้เพิ่มโฟลเดอร์นี้ไว้ในรายการยกเว้น:
- Malwarebytes → Settings → **Allow List** → **Add** → **Allow a file or folder** → เลือกโฟลเดอร์ `GunBeep`
  (ติ๊กให้ยกเว้นทุกการตรวจจับ ถ้ามีตัวเลือก)
